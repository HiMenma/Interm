# Interm 1.0.0

First public release. Interm puts a button on the macOS Finder toolbar that opens a terminal
**in the folder of the front Finder window** — one click, no folder copy-pasting.

Native Swift: AppKit + SwiftUI + a bundled FinderSync extension. No third-party dependencies.

## Highlights

- **One-click from the Finder toolbar** — ⌘-drag `Interm.app` into the toolbar, then a single click opens a terminal at the front window's folder.
- **Finder integration** — the bundled extension adds “Open in Terminal” to right-click menus (window background or selection) and a toolbar menu item.
- **Services menu** — Finder › Services › Open in Terminal, `⌃⌥T` by default.
- **Scriptable** — `open "interm://open?path=/tmp"` and `Interm --open-at <dir>` (`--dry-run` prints the command instead of running it).
- **Multiple terminals** — Terminal (default), iTerm2, Warp, kitty, WezTerm, Alacritty, or a custom app + argument template with a `{dir}` placeholder.
- **Diagnosable** — `Interm --selftest`, plus a settings window showing extension state, the last opened folder and a one-click self-test.

## Requirements

- macOS 14 or newer
- The prebuilt binary is **arm64 only** and **ad-hoc signed, not notarized**

## Install

### From source (recommended)

```bash
git clone https://github.com/HiMenma/Interm.git
cd Interm
make build && make install      # installs to ~/Applications and registers the extension
```

Then ⌘-drag `~/Applications/Interm.app` onto a Finder window's toolbar.

### Prebuilt binary

Download `Interm-1.0.0-arm64.zip` below, unzip, and move `Interm.app` to `~/Applications`.

Because the build is not notarized, Gatekeeper will block the first launch. Either right-click
the app → **Open**, or remove the quarantine attribute:

```bash
xattr -dr com.apple.quarantine ~/Applications/Interm.app
```

### After installing

1. **Toolbar button** — hold ⌘ and drag `Interm.app` onto the Finder toolbar. The first click asks for permission to control Finder (that is how Interm reads the current folder); allow it once.
2. **Finder extension** — System Settings › General › Login Items & Extensions › Extensions › Finder Extensions → tick Interm, or use “Enable / Manage Extension…” in Interm's settings.

## Verify the download

```bash
shasum -a 256 -c Interm-1.0.0-arm64.zip.sha256
```

## Known limitations

- No Developer ID certificate: ad-hoc signed, not notarized, not distributed through the App Store.
- Arm64 only; no universal binary. Build from source on other architectures.
- A FinderSync toolbar item can only open a menu (the SDK has no `toolbarItemClicked`), so the true one-click button is the app icon dragged into the toolbar.
